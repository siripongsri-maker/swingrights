## ขอบเขตและข้อจำกัด
สร้างเฉพาะไฟล์ใหม่ใน docs/handoff/ ไม่มีการแก้แอป ฐานข้อมูล การตั้งค่า หรือเปิด/ปิดฟีเจอร์
การเปิดเว็บและเข้าสู่ระบบอาจเพิ่มบันทึกการเยี่ยมชมและเข้าสู่ระบบตามการทำงานปกติ
คำว่า “ข้อมูลจำลอง” ใช้ตามคำยืนยันของผู้ขอเอกสาร ไม่ได้ตรวจที่มาของเรื่องเล่าทุกรายการ

นี่เป็นฉบับตรวจหลักฐาน ไม่ใช่คู่มือที่มีภาพครบทุกขั้นตามข้อกำหนดเดิม
ส่วนที่ขาดภาพหรือหลักฐานระบุ [ต้องยืนยัน] และไม่สร้างภาพจำลองแทน:
- ภาพหลังเชิญ admin ใหม่ ทดสอบบัญชีใหม่ ระงับ demo ลืมรหัส และเปิด TOTP, ต้องได้รับอนุญาตให้เปลี่ยนบัญชี/การตั้งค่า
- รายงานและ intake ทุกขั้นหลังเล่าเรื่อง รวม AI คัดกรอง เสียง รูป ลายเซ็น และส่งสำเร็จ, ต้องได้รับอนุญาตให้สร้างข้อมูลทดสอบ
- คำถามถึงผู้แจ้ง การตอบกลับ การมอบหมาย เปลี่ยนสถานะ ร่างเอกสาร พิมพ์ และส่งต่อ, ต้องได้รับอนุญาตให้เขียนข้อมูลและบันทึกกิจกรรม
- /welcome และ /me หลังเข้าสู่บัญชีผู้แจ้ง, ต้องมีบัญชีทดสอบที่อนุญาตและไม่แก้ข้อมูลจริง
- หน้าจัดการ Lovable, Publish, History, โดเมน, ค่าลับ และเครดิต, ต้องเข้าถึงหน้าจัดการด้วยสมาชิกที่มีสิทธิ์
- ขั้นตอนคำขอสิทธิ เหตุข้อมูลรั่ว และคำขอรัฐ, ต้องมีนโยบายองค์กรและผู้เชี่ยวชาญกฎหมายตรวจ
- กำหนดเก็บรักษา สำรอง และกู้คืน, ยังไม่มีหลักฐานการตั้งค่าหรือทดสอบจริง
- แผนผังเส้นทางเป็นข้อความประกอบภาพจริง ไม่ใช่ภาพแผนผังต่อด้วยภาพครบทุกหน้า

## ผลตรวจเอกสาร
ใช้แนวทาง PDF Processing Guide ในการสร้างและตรวจทุกหน้า
แปลง PDF ครบ 87 หน้าเป็นภาพ ตรวจภาพทุกหน้าผ่านชุดภาพรวม และตรวจหน้าตัวอย่างที่มีข้อความหนาแน่นขนาดเต็ม
ตรวจตัวอักษรไทย ภาพ สารบัญ เลขหน้าและข้อความภายในองค์กร ไม่พบหน้าว่าง ข้อความล้นหรือทับกันจากการตรวจขอบเขตและภาพ
แก้วงชี้ที่ไม่ตรงจุด เลขขั้น และคำอธิบายแผนที่ Google ที่ภาพจริงแสดงข้อผิดพลาด
ยังต้องให้ผู้รับมอบตรวจชื่อปุ่มและวงชี้แต่ละงานก่อนใช้เป็นคู่มือปฏิบัติงาน
ส่วนกฎหมายท้ายเล่ม 3 มี 5 หน้า เป็นร่าง ไม่ใช่ความเห็นทางกฎหมาย
